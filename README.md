# 聊天模拟器（心笺）

一个单文件的微信风格聊天模拟应用，无需后端，直接打开浏览器即可使用。支持私聊、群聊、语音、红包、亲属卡、视频通话、朋友圈、抉择（帮我决定 / 寻求意见 / 塔罗占卜 / 心笺问答）、报备查岗、时间轴等丰富功能，适合情侣/亲密关系间的日常模拟陪伴。

## 功能特性

### 💬 聊天
- 私聊与群聊，消息类型：文本、语音（可录音或从语音库选取）、图片、红包、亲属卡、拍一拍
- 引用、撤回、删除消息
- "对方正在输入"提示、消息已读状态（未读粉色圆点）
- 自动回复、定时消息、回复设置（查岗/报备/视频通话时长等）

### 📞 通话
- 视频通话（虚拟/真实摄像头）、通话时长记录
- 通话记录：拒绝 / 挂断 / 未接听，均以双方昵称生成记录
- 通话悬浮窗、画中画模式

### 🔮 抉择板块
- 帮我决定：设置问题与选项，对方在指定时间后替你决定
- 寻求意见：向联系人提问并收集回答
- 塔罗占卜：经典塔罗（正逆位）与雷诺曼两副牌，支持抽一张/抽三张
- 心笺问答：创建问卷（单选/多选/打分/排序/开放题）、模板库、对方问题库、答卷统计

### 📸 社交
- 朋友圈（发布、点赞、评论、删除）
- 报备 / 查岗 / 打卡、时间轴记录
- 信箱（写信件）、心情记录、暖记

### ⚙️ 个性化
- 外观主题切换（多套粉色系主题）、我的头像/昵称/状态
- 专属字卡、专属表情包、专属语音、通用语音库、表情包/颜文字
- 联系人管理：头像、备注、状态、专属回复设置
- 数据管理：一键导出 / 导入全部数据（IndexedDB），模块化选择导出

### 🔋 后台保活
- 开启后页面在浏览器后台也能继续收到弹窗和消息（播放极低频声音，人耳几乎听不见）

## 快速开始

直接双击打开 `index.html`，或部署到任意静态托管（GitHub Pages / Vercel / 本地 http 服务）后访问。

> 建议通过 `http://` 或 `https://` 协议访问，`file://` 下部分浏览器特性（录音、摄像头等）可能受限。

## 文件说明

```
├── index.html          # 主文件（全部页面、样式与逻辑，单文件应用）
├── css/all.css         # 样式文件（index.html 引用）
└── js/
    ├── main.js         # 逻辑脚本（index.html 引用）
    └── bottombar.js    # 底部栏相关脚本
```

## 数据存储

所有数据（联系人、聊天记录、设置、朋友圈、问卷、塔罗记录等）保存在浏览器 IndexedDB 中，可通过"数据"页导出为 JSON 备份或迁移。

## 技术栈

- 原生 HTML / CSS / JavaScript（无框架、无构建步骤）
- IndexedDB（数据持久化）
- Font Awesome 4.7（图标，CDN）
- Web Audio API（后台保活、语音）

## 注意事项

- 首次使用会请求麦克风权限（用于语音），仅请求一次
- 头像使用 picsum.photos 占位图，离线时可能显示失败（可自行更换为本地图片）
